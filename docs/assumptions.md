# ClinicFlow — القرارات المعمارية والافتراضات المعتمدة (Assumptions & Decisions)

## 1. الهوية والربط التقني (Base URL & Connectivity)
- **Base URL المعتمد**: تم الحفاظ على العنوان الفعلي المضبوط مسبقاً في بيئة المشروع: `https://localhost:44341`.
  - يتطابق تماماً مع إعدادات IIS Express في مشروع `ClinicFlow_API` (`sslPort: 44341`).
  - تم ربط Angular SSR والمتصفح على نفس العنوان دون تغيير عشوائي.
  - تم تعزيز الـ Interceptors لعرض رسائل خطأ عربية ودية عند تعذر الوصول للخادم (Network error / status 0).

## 2. التسجيل الذاتي والتحقق الثنائي (Self-Registration & SMS OTP)
- يتم التسجيل عبر مسار `POST /api/public/registration/draft` مع فحص فوري ومباشر لتوفر معرّف العيادة (Slug Availability).
- يتم توليد رمز تحقق مكوّن من 6 أرقام (Cryptographically secure OTP) وتشفيره باستخدام `SHA-256` داخل قاعدة البيانات (`RegistrationDrafts`).
- مدة صلاحية الرمز 5 دقائق مع عد تنازلي مباشر وحظر إعادة الإرسال لمدة 60 ثانية (Rate-limiting & cooldown).
- عند تأكيد الرمز (`POST /api/public/registration/verify`) يتم تفعيل فترة تجريبية مجانية كاملة المزايا لمدة 30 يوماً (`TrialEndsAtUtc`).
- يتم إنشاء حساب مدير العيادة (Admin User) وتجهيز توكن الدخول المباشر.

## 3. التجهيز التلقائي للتخصصات الطبية (Auto-Provisioning)
- فور نجاح التحقق من الـ OTP، يتم استدعاء محرك التجهيز الذاتي الذي ينسخ كتالوج التخصصات الوطنية المرجعية (25 تخصصاً طبياً معتمداً) إلى جدول التخصصات الخاص بالعيادة (`ClinicSpecialties`).
- كل تخصص يحمل: الاسم العربي، الكود، الوصف الطبي، وأسباب الكشف الافتراضية، مع ربطه التلقائي برمز الـ Tenant الخاص بالعيادة لضمان العزل التام.

## 4. لوحة الإدارة المركزية (Super Admin Platform Console)
- المسار المعتمد: `/super-admin/**` مع حماية صارمة عبر `SuperAdminGuard` وتوكنات منفصلة.
- يتم تهيئة حساب مالك المنصة المبدئي (Platform Owner) تلقائياً عند أول إقلاع للباك إند عبر:
  - اسم المستخدم: `superadmin`
  - كلمة المرور: `SuperAdmin@2026!`
- يدعم النظام تعدد المشرفين (Staff Admins) مع منح صلاحيات حبيبية (Granular Permissions) مثل `Clinics.Manage`, `Plans.Manage`, `Payments.Review`, `Cms.Manage`, `Specialties.Manage`.
- **مبدأ الخصوصية الصارم**: المنصة لا تملك أي واجهات أو استعلامات للوصول إلى الملفات الطبية، التشخيصات السريرية، أو روشتات المرضى لأي عيادة (Multi-Tenant Zero-Knowledge Data Privacy).

## 5. الاشتراكات والمدفوعات اللامركزية (Subscriptions & Manual Payments)
- تتوفر 3 باقات رئيسية: Basic (الأساسية)، Professional (المتقدمة)، Business (المراكز والعيادات الكبرى) بالإضافة لباقة Trial.
- في حال انتهاء فترة التجربة أو الاشتراك، يدخل حساب العيادة في **وضع القراءة فقط (Read-Only Mode)**، حيث يُسمح بتصفح البيانات واستخراج التقارير، بينما يتم حظر العمليات التشغيلية (إنشاء حجوزات جديدة، كشوفات) وإرجاع كود `403 Forbidden` برسالة عربية واضحة.
- يدعم النظام السداد اليدوي اللامركزي (InstaPay, Vodafone Cash, تحويل بنكي مباشر) مع إرفاق رقم المرجع وصورة الإيصال وكوبونات الخصم الترويجية، ليقوم مشرفو المنصة بمراجعتها واعتمادها فورياً.
